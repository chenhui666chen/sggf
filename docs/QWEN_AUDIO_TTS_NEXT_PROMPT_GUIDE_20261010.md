# qwen-audio-3.1-tts-next 提示词书写技巧与实验结论

> 平台：耳畔星河（novel_writing_agent）
> 日期：2026-10-10
> 适用范围：**仅 `qwen-audio-3.1-tts-next`（Audiogen，整段音频生成）**。朗读 TTS（qwen3-tts-instruct-flash、qwen-audio-3.1-tts-flash、cosyvoice、minimax、mimo、stepaudio、seed-tts 等）的提示词写法**本轮未做真实测试**，本文技巧不得直接套用。

## 1. 一句话结论

在 Next 上，**"官方示例式逐行结构 + 少量关键声事件写明时序与质感 + 明确人声优先级"** 是目前唯一经过人耳确认有效的写法；它在简单场景（2 角色、若干句对白、1–2 个音效、可选配乐）效果好，在复杂多事件场景（雷暴、奔跑、法术、石门同时要求）**没有证据表明能挽救**。

## 2. 书写技巧（可复用部分）

### 2.1 总体结构：一段"总纲" + 按时间顺序逐行标签

开头用一段散文写清全局约束，随后按剧情时间顺序逐行给出标签，每行一件事。经人工确认有效的标签集：

```
【角色】【音效】【配乐】【旁白】【对白】
```

总纲要点明（实测这些约束能被遵守）：目标时长区间、成品按哪个标签顺序生成、**只朗读【旁白】与【对白】引号内的原文**、不朗读标签/角色说明/括号内表演提示、保留所有句子标点与顺序、**人声在前景、环境音在后方**、台词之间留自然停顿、不添加与剧情无关的人声或电子噪声。

### 2.2 角色：声线集中定义，跨片段保持一致

每个角色一行：`【角色：名字（年龄、性别、音色、气质、语速）】`。把音色与语速写全，是双人可辨识的主要抓手。同一场景需要延续上一段人物时，**重复粘贴同一段声线描述**（实测"男子2 沉稳略沙哑、窄带、稍远但每字可懂"能维持电话另一端的空间差异）。旁白与角色对白分标签写，旁白单独给声线与语速。

### 2.3 音效：写"位置 + 先后 + 质感 + 遮蔽关系"，不要只堆名字

只说"有雨声、脚步声、门响"时，模型可能只保证"有声音"而时序与音色不可辨。有效的写法是一行一个事件，并显式说明：

- 什么时候出现（"旁白说完后""第二句与第三句之间的对白空隙""第四句尾音完整落下后"）；
- 与其他事件的先后（"先是汽车行驶掠过，再接两声分开的高跟鞋踏地声，留出先后顺序，不混成一团"）；
- 质感与可辨识性（"短促、清亮、可辨的'叮'声"）；
- 与人声的关系（"始终低于人声，不盖住词句""不在人声下持续敲击"）；
- 负向约束（"不是电子提示音""不与对白重叠""绝不补入电话忙音、按键音、额外人物"）。

人耳确认：按这种"声景时间线"写法生成的电话戏下半段，对白间隙的马林巴短音可辨、结尾汽车与脚步声先后清楚；而**刹车声仍不明确**，说明质感类描述可提高可辨率但不保证落实。

### 2.4 配乐：用 3–4 个节点控制"进入—变化—退让—淡出"

官方示例没有配乐段，以下是本次实测被人耳确认"这个配乐方式没问题，效果很好"的写法：在【音效】之后插入首个【配乐】声明音色与优先级，之后在情绪转折点、关键音效处、结尾回应处各插一条。要点：

- 首个【配乐】写明乐器、情绪、节奏，并强调**环境音仍属音效，不要用音乐代替**；
- 每次有人说话时声明"配乐退到人声后方，不盖住字词"；
- 关键音效处写"碰罐的瞬间稍退，不能用铃音冒充易拉罐"——同时处理优先级与音色混淆；
- 情绪转折处只写和声变化，并加负向约束"不要出现强鼓点或煽情旋律"；
- 结尾写"始终轻于人声，随旁白与环境音一起自然淡出"。

这是**同素材对照**（台词、角色、原有音效行逐字不变，只新增【配乐】）的做法，改法本身用字符串替换保证不引入台词漂移。

### 2.5 情绪与表演：把"指令遵循"和"故事情绪适配"分开写

括号内给表演提示（`（嗓音低沉，略带疲惫）`），句间留白让转折可听。评价时须区分两个可能相反的目标：是否**遵守了表演指令**（如"刻意平直冷漠"），与是否**符合故事情绪**（团圆场景本该狂喜）。混成一个分数会得到自相矛盾的结论。

### 2.6 台词保真

- 明确"严格按下面顺序只朗读引号内 N 句"，并在末尾写"末句结束后……不追加台词"；
- **保持原文专名与字形，不擅自统一**（示例中上一段"李勋"、下一段"李峋"是原始差异，实测模型按指令各自保留）；
- 不读角色名、不读说明。

### 2.7 规模控制

限制同一片段的角色数、对白数与声事件数。反例：神话"灵山异变"要求雷声、奔跑、法术、石门等多个事件，实际只有 9.504 秒且关键事件大多缺失或难以辨认；改成官方示例式逐行结构后**反而缩短到 3.504 秒**。长场景应切分成可控片段分别生成。

### 2.8 时长只能"表达"不能"指定"

Next 没有时长入参，提示词里的"目标约 35 至 50 秒"只是意图。实测对照（同一写法下的波动）：屋顶原版与配乐版均 40.032 秒（目标 35–50 秒，达成）；电话上半段 42.024 秒、下半段 29.304 秒（目标 45–65 秒，均未达成）；灵山异变 9.504 / 3.504 秒。结论：**写目标时长有帮助但不可依赖，交付前必须用完整解码核验实际秒数**。

## 3. 本轮样本与人耳裁定（结论证据链）

所有裁定来自用户亲自试听，模型意见只作为观察，不作为真值。

| 样本 | 写法 | 实测秒数 | 人耳确认的结论 |
|---|---|---|---|
| 广告播音（Pocara 改编） | Seed-Audio 段落式 | 30.024 | 要求的"慢速、平缓、柔和"**未实现**，实际语速偏快；模型高分不能推翻人耳 |
| 悲伤独白 | Seed-Audio 段落式 | 20.04 | 疑似多出鼻音、末句被拆开**属实** |
| 疗养院旁白 | Seed-Audio 段落式 | 25.032 | 同一旁白的语气切换**可辨** |
| 电话戏上半段 | 台词保真 + 声线定义 | 42.024 | 双人声线与空间差异可区分 |
| 电话戏下半段 | **声景时间线** | 29.304 | 马林巴短音可辨、汽车与脚步先后清楚；**刹车声不明确** |
| 宫廷试药前段 | 官方示例式 | 38.904 | 金属"唰"声不清晰；布鞋脚步可几乎听出但**时机提前**；两次抓衣摩擦分得开却**不像抓衣**；俘虏不够沙哑磕巴，快速轮换仍可能混淆 |

## 4. 自动评分器观察（阶段性，非最终排名）

本轮共 29 段新生成音频、约 105 次评分调用，四模型（doubao-seed-2-1-lite、qwen3.5-omni-plus、qwen3.5-omni-flash、qwen3.8-omni-flash）JSON 解析失败分别为 3 / 0 / 2 / 2 次，无自动重试。

- **没有固定胜者**：电话戏与灵山异变上 Qwen3.8 Flash 的声景判断更贴近人耳；屋顶对话上豆包（两次碰罐、男声区分）更准确；Plus 在灵山异变声称"丰富音效"是误报。
- **可解析不等于可信**：豆包在 9.504 秒音频上给"时长契合"5 分，与客观解码时长直接矛盾。
- **一致性不是真值**：多个模型意见一致也不能替代人工试听；分歧时应并列各模型声称听到的具体内容，由人裁定，允许"两边都部分正确"。
- 曾建议的"Qwen3.8 Flash 主评 + 豆包复核"只是阶段性分工，不得当作固定结论。

## 6. 可直接套用的模板（本次实测通过的两条）

### 6.1 官方示例式 + 配乐（屋顶对话，861 字，实测 40.032 秒）

```text
中文都市夜景广播剧，目标约35至50秒。按以下【角色】【音效】【配乐】【旁白】【对白】顺序生成成品；仅朗读【旁白】和【对白】引号中的原文，不朗读标签、角色说明或括号内表演提示。保留所有句子、标点和顺序；人声在前景，环境音在后方，台词之间留自然停顿，不添加与剧情无关的人声或电子噪声。
【角色：旁白（30岁女性，沉静、有故事感，语速舒缓）】
【角色：阿哲（28岁男性，嗓音低沉、略带疲惫但真诚，语速偏慢）】
【角色：大刘（28岁男性，嗓音爽朗、乐观、中气足，语速快）】
【音效：远处城市持续的低鸣与轻微晚风声，空间开阔，始终低于人声，不盖住词句。】
【配乐：开场是一层很轻的温暖电钢琴与低音量长音铺底，节奏舒缓、略带怀旧；城市低鸣和晚风仍属于环境音，不要用音乐代替。有人说话时配乐退到人声后方，不盖住字词。】
【旁白：（沉静，有故事感）"城市的灯在脚下连成一片。阿哲灌了一口酒，忽然开口。"】
【对白：阿哲：（嗓音低沉，略带疲惫）"你说，我们是不是把日子过成了当年最讨厌的样子？"】
【对白：大刘：（语气爽朗，略带不解）"怎么突然这么丧。"】
【对白：阿哲：（语气无奈，自嘲）"今天开会，我居然会打官腔了。"】
【对白：大刘：（笑着说）"那叫成熟。"】
【对白：阿哲：（语气低沉，带一丝迷茫）"成熟……还是磨平了？"】
【配乐：在这句结束后的停顿里，和声短暂变得更空、更低落；大刘回应前不要出现强鼓点或煽情旋律。】
【旁白：（语速更缓，声音轻柔）"大刘没立刻回答，碰了碰他的罐子。"】
【音效：旁白说完后，两只易拉罐轻碰，只有一下短促、清亮、可辨的"叮"声；不是电子提示音，不与对白重叠。】
【配乐：碰罐的瞬间稍退，不能用铃音冒充易拉罐。】
【对白：大刘：（语气坚定，带着笑意）"管它呢。至少今晚，咱俩还是当年那两个小子。"】
【配乐：回应之后才微微转暖，始终轻于人声，结尾随旁白与晚风一起自然淡出。】
【旁白：（声音渐轻，像融进风里）"夜风里，两个人都笑了。"】
【音效：晚风保持轻柔，尾音自然淡出；不再添加人声或音效。】
```

### 6.2 声景时间线（电话戏下半段，625 字，实测 29.304 秒）

```text
中文双男声电话悬疑剧下半段，目标约45至65秒。延续上一段的两个人物：男子1为中青年男性，台湾口音、低沉浑厚、成熟，近距离清晰发声；男子2为中年男性，台湾口音、沉稳略沙哑，从电话另一端传来，轻微窄带、稍远但每字可懂。声线和空间要可区分，不读角色名。男子1由不解转为尖锐质疑；男子2先平静解释，最后无力、带宿命感，语速放缓、尾音收住。四句对白依次完整朗读，句间自然留白。保持原文中"李峋"的字形，不擅自与上一段"李勋"统一，不读任何说明。
声景时间线：开头即接续通话，没有新的拨号、手机震动或提示音。远处稀疏、轻微的鸟鸣留在背景，不与人声争前景；每句说话时，低音量弦乐和柔和的 pad 只作悬疑铺底，不产生连续电子嗡鸣。第二句与第三句之间的对白空隙，马林巴敲出短暂、可独立辨认的几颗低音，不在人声下持续敲击。第四句尾音完整落下后音乐淡出；随后近处有短暂的汽车行驶掠过、一声轻微轮胎制动声，再接两声分开的高跟鞋踏地声，留出先后顺序，不混成一团，不盖住对白。绝不补入电话忙音、按键音、额外人物或对白。
只按顺序逐字朗读以下四句引号内台词：
男子1："为什么？"
男子2："据说跟青龙帮的帮规有关，细节我也不清楚。只知道男公馆对他们来说，是个不能动手的地方。"
男子1："我就当你被阿标收买了，那你打这通电话的意图是什么？不是应该希望李峋落入他们手里吗？"
男子2："有些事，不是我能选择的。宇川，这是我唯一能做的。保护好李峋，也保重自己。"
末尾干净淡出。
```
