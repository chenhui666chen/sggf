## 引言

拾光工坊（下称"本服务"）是一个面向创作者的 AI 写作、有声书制作与短剧制作工具。对你产生的媒体资产（图片、视频、音频），本服务默认采用"本地优先"存储：资产副本默认保存在你的设备本地，服务端仅保存必要的元数据与用于功能实现的受控副本。我们深知个人信息对你的重要性，将以本政策说明我们如何收集、使用、存储、共享与保护你的个人信息，以及你可以如何管理。

**请在注册前仔细阅读本政策。勾选同意本政策即表示你已充分理解并接受其全部内容。**

**单独同意提示**：本政策是对个人信息处理活动的整体告知。当处理涉及敏感个人信息（如手机号），或需要将你的内容提供给第三方 AI 服务商处理（见第四节）时，我们会在对应操作界面另行说明处理细节，并通过独立的勾选框或弹窗取得你的单独同意；在你完成该等勾选前，我们不会进行相应处理。你可以在"用户中心 → 同意记录"随时查看与撤回各项同意。

## 一、我们收集的个人信息

| 信息类型 | 字段 | 是否必需 | 对应同意项 |
|---|---|---|---|
| 账户标识 | 用户名、邮箱 | 必需 | 《隐私政策》 |
| 账户展示 | 昵称（默认同用户名）、头像 | 选填 | 《隐私政策》 |
| 登录凭据 | 密码（仅存 bcrypt 不可逆哈希） | 必需（密码登录时） | 《隐私政策》 |
| 手机号 | 手机号 | **选填** | 《隐私政策》+ **手机号收集单独同意**（敏感个人信息） |
| 第三方标识 | 支付宝 openid / 微信 openid / 微信 unionid | 使用第三方登录时 | 第三方资料同步单独同意 |
| 安全审计 | IP 地址、User-Agent | 必需（安全目的） | 《隐私政策》 |
| 创作内容（文本） | 小说/剧本文本、分镜与画面描述 | 使用对应功能时 | 《隐私政策》 |
| 媒体资产（图片/视频/音频） | 你生成或上传的图片、视频、音频素材及音色配置 | 使用对应功能时 | 《隐私政策》（媒体资产默认本地存储，见第三节） |
| 验证码 | 邮箱验证码 | 对应操作时 | 《隐私政策》 |

**我们不收集**：真实姓名、身份证号、年龄/出生日期、位置信息、通讯录、生物识别信息（TTS 音色素材仅用于配音生成，不用于声纹识别，不构成生物识别信息）。

**年龄核验方式**：我们不收集年龄、出生日期等信息（见上文"我们不收集"）。为执行本政策第八节所述未成年人限制，注册或首次创建账户时，你需要勾选"我已年满 14 周岁"的自我声明。该勾选属于使用资格确认，不构成年龄、出生日期等个人信息的收集；勾选记录将作为一条同意/声明记录留存（见第三节"同意记录"与第八节）。

**第三方标识的存储方式**：openid/unionid 在数据库中以"确定性查找哈希 + 加密密文"双字段存储，**不落明文**；密钥与数据分离保管。据此我们无法直接看到明文标识，等值匹配通过哈希完成。

**安全审计字段**：IP 地址与 User-Agent 仅在安全审计日志中存储**哈希值**（加盐 HMAC），不存原文，保留 90 天后自动删除。

## 三、我们如何存储个人信息

**存储方式与地点**：本服务按数据类型分层存储：

| 数据类型 | 存储位置 |
|---|---|
| 账户与文本内容（账号、小说/剧本文本、分镜、积分等） | 境内服务器（数据库为境内节点） |
| 媒体资产（图片/视频/音频） | **默认保存在你的设备本地**（浏览器本地存储 OPFS/IndexedDB，或你授权指定的本地目录）；服务端仅保存元数据与来源地址 |
| 媒体资产的云端副本 | 仅当你选择收录至平台、需要跨设备访问或平台受控保存时，副本存于境内对象存储/服务器 |
| 生成处理中的临时文件 | 仅在 AI 处理期间暂存于境内服务器，任务结束或过期后删除 |

**本地优先提示**：媒体资产副本保存在你的设备上，清除浏览器数据、更换设备或删除应用数据可能导致本地副本丢失；服务端元数据与来源地址仍保留，你可据此重新收录或回源获取。

**保存期限**：

| 信息 | 期限 |
|---|---|
| 账户信息 | 账户存续期间 |
| 注销后的账户信息 | **30 天冷静期**后匿名化处理（用户名替换为不可还原的随机标识，邮箱/手机号/密码/第三方标识全部删除） |
| 同意记录 | 永久保留（作为已取得同意的证明，匿名化处理保留） |
| 安全审计日志（IP/UA 哈希） | 90 天，到期自动删除 |
| 验证码 | 数分钟级短期有效，过期自动删除 |
| 账单与计费记录 | 依法保存 7 年；其中与计费无关、可直接识别身份的附加信息将删除或去标识化，仅保留财税核验所必需的交易与支付凭证字段 |
| 密码 | 仅存不可逆哈希，任何情况下不可还原 |
| 媒体资产（你设备上的本地副本） | 存续于你的设备；清除浏览器数据可能导致丢失 |
| 媒体资产（服务端元数据与云端副本） | 账户存续期间；账户注销后按"注销后的账户信息"处理，云端副本一并删除 |
| 生成处理中的临时文件 | 处理完成或过期后自动删除 |

## 五、Cookie 与同类技术

本服务使用 Cookie 维持登录状态与安全防护，**不用于广告跟踪**：

| Cookie | 属性 | 作用 |
|---|---|---|
| 登录态令牌 | **仅浏览器可读**（httpOnly）+ SameSite=Lax | 维持登录，JavaScript 无法读取 |
| 刷新令牌 | 仅浏览器可读（httpOnly）+ SameSite=Lax | 静默续期登录状态 |
| CSRF 令牌 | SameSite=Strict | 防"跨站伪造请求"攻击的安全校验 |

你可以通过浏览器设置清除 Cookie，但这将导致需要重新登录。

**本地存储技术**：为实现媒体资产的"本地优先"存储，本服务还使用浏览器本地存储（OPFS、IndexedDB）在你的设备上保存媒体资产副本；在你授权后，也可将副本写入你指定的本地目录（文件系统访问 API）。这些数据保存在你的设备上，我们无法直接访问；你可在"用户中心"随时清理本地副本。清除浏览器数据将删除这些本地副本（服务端元数据与来源地址仍保留）。

## 六、你的权利

按相关法律，你对个人信息享有以下权利，可通过产品功能或联系个人信息保护负责人行使：

1. **查阅与更正**：在"用户中心 → 账户与安全"查看并修改昵称、头像、手机号、绑定关系；
2. **导出**：使用"导出我的数据"功能（用户中心），获取你的个人信息与同意记录副本；
3. **删除**：通过"注销账户"发起删除。为防误操作并处理未完结交易与未消耗权益，账户注销后进入 30 天冷静期，期满后匿名化处理，服务端保存的媒体资产云端副本一并删除；冷静期内可随时联系负责人撤回注销。如你确认账户无未完结交易且未消耗权益，希望立即删除个人信息的，可联系个人信息保护负责人申请即时删除，我们将在 15 个工作日内删除服务端个人信息（存在法定留存义务的字段除外）；
4. **撤回同意**：你可随时在"用户中心 → 同意记录"查看各项同意的历史；撤回单项同意可联系负责人，或通过注销账户撤回全部同意。撤回不影响撤回前基于同意的处理；
5. **注销**：注销后我们将停止为你提供服务，并按第三节所述期限与方式处理服务端信息。注销作用于服务端保存的信息，**存于你设备本地的媒体资产副本不随注销删除**，你可在设备端自行删除；
6. **管理本地副本**：你可在"用户中心"查看、清理或重新收录保存在设备本地的媒体资产副本；清理本地副本不影响服务端元数据与来源地址。

我们将在 15 个工作日内响应你的请求。

## 八、未成年人保护

本服务**不面向不满 14 周岁的未成年人**。

- 注册或首次创建账户时，你必须勾选"我已年满 14 周岁"的自我声明，未勾选将无法注册（见第一节"年龄核验方式"）；
