# I18N 内容类定界登记（P3-X）

> P3 批次（前端全站 i18n）推进过程中，对「不翻译的中文」逐条甄别的登记册。
> 更新时机：新增/发现内容类条目时登记；登记只证明「现状与判定」，不改变代码。

## 判定标准（满足任一即归内容类，不翻译）

1. **后端业务数据**：发送给后端 API / 入库存储的字段值（world_settings、audio asset description、task reason…），翻译会破坏后端语义或数据一致性。
2. **labelKey 机制后备值**：`{ value, label: '中文', labelKey: 'xxx' }` 结构中的中文 label——UI 渲染优先 `t(labelKey)`，中文仅作 t 缺失时的回退。
3. **API 错误文案层**：把后端错误码/结构化 detail 映射为中文提示的函数（含测试断言中文），本质是「服务端文案的客户端镜像」。
4. **内容枚举 label**：产品固定术语/阶段配置数据（key 用于状态机与后端日志，name/desc 供展示）。
5. **代码注释/开发日志**：扫描器误报的 `{/* 注释 */}` 与 logger 输出。
6. **内容数据/模型档案正文**：厂商模型知识文档摘要、使用指南正文、能力说明 note、代码示例模板等产品内容正文，不随 UI 语言翻译；多语言需内容管线或后端数据源承载（与类别 1 的“发后端”不同，本条为纯展示/透传内容）。
