- 每个模型条目使用稳定的 id 作为唯一标识，其他配置通过该 id 引用，避免硬编码名称。
- capabilities 字段统一采用 name/support_level/description 三元组，support_level 取 native/emulated/unsupported 三值之一，并附带 source/verified_at/confidence 用于溯源。
- 路由相关配置（llm_models.routing、model_catalog_profiles.router_rules）均使用 when/action/reason 三段式描述触发条件、动作与原因，便于审计与调试。
- 提示词模板统一放在 prompt_template 或 prompt_patterns[].template 字段，示例放在 prompt_examples 数组中，保持模板与示例分离。
- 成本与性能指标集中在 cost_profile/performance 块内，包含 unit/price/currency 及 latency、tokens_per_second 等量化指标，货币单位显式声明（CNY/USD）。
- 所有可枚举的标签（styles、tags、task_types、priorities、quality_levels）均以扁平列表形式定义，便于前端下拉选择与校验。
