本模块由四个 YAML 配置文件构成，按职责分层：
- `models.yaml`：最底层的模型注册表，每个模型条目包含 id、provider、version、modality、capabilities（含 support_level/score/source/verified_at/confidence）、constraints（duration/ratios/分辨率等）、quality_metrics、cost_profile、rate_limit、default_params、fallback_strategies、endpoint、auth_method、summary、recommended_scenarios、limitations、integration_notes、documentation_url、source_urls、tags、detailed_specs 等字段，是运行时加载的权威来源。
- `llm_models.yaml`：LLM 专用配置，结构比 models.yaml 更丰富，增加 capabilities（name/level/score/description）、api_config（api_key_env/base_url/default_timeout/default_max_retries）、performance（quality_score/latency/cost/tokens_per_second）、routing（task_types/priority/fallback_models/weight/enabled）、default_params、summary/recommended_scenarios/limitations/integration_notes/best_practice_tips/documentation_url/source_urls/tags 等，用于 LLM 路由与参数注入。
- `model_catalog_profiles.yaml`：模型档案中心，以 model_id 为键定义 role_summary、system_role、prompt_patterns（title/template）、router_rules（when/action/reason）、best_practice_tips、tooling_badges、project_entrypoints、local_deployment_note，承担“提示词模板 + 路由规则 + 项目级入口”的编排层。
- `intent_domains.yaml`：意图解析域知识，按 domain（wan/tts/runway/kling）组织 modalities、creative_modes、styles、camera_movements、shot_types、compositions、lighting_times、emotions、prompt_template、prompt_examples、parsing_rules、constraints、scene_rules，为意图识别器提供领域词典与场景推荐逻辑。

依赖方向：上层运行时（media_runtime / task_router / intent_parser）单向读取这些 YAML，YAML 之间通过 id 相互引用（如 llm_models 的 fallback_models、model_catalog_profiles 的 router_rules 指向具体 model_id），形成“注册表 → 路由档案 → 意图域”的单向依赖链。
