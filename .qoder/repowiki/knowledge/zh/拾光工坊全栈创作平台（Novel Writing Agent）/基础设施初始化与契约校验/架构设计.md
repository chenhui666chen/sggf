本模块由三个相互独立的子部分组成：
- `postgres-init/01-init.sql`：PostgreSQL 初始化脚本，通过 `CREATE EXTENSION IF NOT EXISTS` 启用 uuid-ossp、pg_trgm、btree_gin 扩展，并设置时区、统计、内存及 IO 相关运行参数，作为容器化部署时的数据库初始化入口。
- `ssl/`：存放 SSL 证书占位文件（cert.pem、key.pem）及说明文档，配合 docker-compose.yml 通过 `.env` 中的 `NGINX_SSL_CERT_PATH` / `NGINX_SSL_KEY_PATH` 变量挂载真实证书，未设置时回退到本地占位文件。
- `.github/workflows/contracts.yml`：GitHub Actions 工作流，监听 frontend 和 backend 中 contracts 相关文件变更，在 Ubuntu 上并行安装 Python 3.11 与 Node.js 20，执行 `scripts/generate_user_asset_local_storage_contract.py --check` 验证派生产物与 schema 同步，再分别运行后端 pytest 和前端 vitest 契约测试及类型检查。
依赖方向单向：工作流依赖 scripts 与前后端契约代码，SSL 目录仅被 docker-compose 读取，三者之间无内部耦合。
