- 所有对外暴露的公共函数都通过 `from __future__ import annotations` 启用 PEP 563 延迟求值，避免循环导入。
- 对不可信输入一律先做类型守卫与 strip() 清洗，再用 try/except 捕获异常并回退默认值，禁止向上抛出未处理异常。
- 状态机阶段执行统一用 `with _stage_timer(ctx.payload, stage=stage_label(state)):` 包裹，确保每个阶段耗时与成功/失败计数被记录到 telemetry.stages。
- 配置项读取遵循 `payload.get('key') if isinstance(payload.get('key'), dict) else {}` 模式，再对字符串字段做 `.strip().lower()` 标准化。
- 列表/集合输入统一通过内部 `_as_str_list` / `_as_int_list` 工具函数进行去重与限长（默认 limit=200），防止恶意或异常数据导致内存膨胀。
- 可选增强逻辑（如智能调参、预生成视频提示词）均用 `try/except Exception: pass` 包裹，确保主流程不因辅助功能失败而中断。
