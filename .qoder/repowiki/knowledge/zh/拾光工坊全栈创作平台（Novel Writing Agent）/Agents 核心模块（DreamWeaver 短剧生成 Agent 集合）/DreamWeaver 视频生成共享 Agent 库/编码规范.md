- 每个 Agent 暴露顶层 `run(ctx: Any) -> None` 函数，从 `ctx.payload` 读取输入并写回结果，失败时抛出异常或由上层捕获。
- 环境配置统一通过 `os.getenv` + `_env_flag`/`_env_int`/`_env_float` 辅助函数读取，带默认值与类型转换容错。
- LLM 调用均通过 `llm_client.chat_completions` + `llm_stream_context` 包裹，使用 `extract_json_object`/`extract_json_array` 解析返回，错误路径记录 `llm_error` 字段。
- 数据类使用 `@dataclass` + `to_dict`/`from_dict` 成对方法实现 JSON 序列化，配合 `json.dump(ensure_ascii=False, indent=2)` 持久化到 run_dir 下的 `.json` 文件。
- 外部命令（ffprobe/ffmpeg）通过 `subprocess.run` 调用，统一捕获异常并返回 None/0 等安全默认值，避免中断主流程。
- 字符串/数值输入一律先做类型检查与 strip，再尝试转换，失败时回退到默认值，所有 except 块统一用 `# noqa: BLE001` 抑制警告。
