本模块以 `agents/` 下的独立 Python 文件组织，每个文件对应一个职责单一的 Agent 或工具类，通过统一的 `run(ctx)` 函数入口（如 `planner.py`、`editor.py`、`scripter.py`、`storyboarder.py`）被上层调度器调用；`dreamweaver.py` 仅作为 `agents.dreamweaver_agent_pkg.run_video` 的薄包装入口。

- LLM 层：`llm_client.py` 集中封装 DeepSeek/DashScope 双后端选择、模型解析、JSON 提取、流式上下文 `llm_stream_context`，被 `planner.py`、`vlm_utils.py` 等复用。
- 资产与提示词：`prompt_fragments.py`、`asset_library.py`、`semantic_asset_index.py`、`reference_image_selector.py`、`best_image_selector.py` 构成素材筛选与提示词拼装层，依赖 `pipeline.media_presets` 做分辨率/比例归一化。
- 音频管线：`simple_audio_sync_manager.py`、`performance_audio_sync_manager.py`、`optimized_audio_sync_manager.py`、`cross_batch_audio_manager.py`、`voice_consistency_manager.py`、`high_performance_voice_consistency_manager.py`、`performance_voice_consistency_manager.py`、`simple_voice_consistency_manager.py` 形成多实现策略族，统一通过 `SimpleVoiceConsistencyManager`/`VoiceConsistencyManager` 抽象缓存与指纹匹配，底层调用 `adapters.adapter_helpers.synthesize_speech_sync`。
- 镜头与相机：`camera_states.py`、`camera_tree.py` 将 storyboard 聚合为按 cam_idx 分轨的 State 序列，供后续生成阶段做依赖定位。
- 媒体处理：`editor.py` 负责 ASS/SRT 字幕写入与 ffmpeg 合成，`image_edit_utils.py`、`painter.py`、`lipsync_manager.py`、`sound_effect_manager.py`、`auditor.py` 分别处理图像编辑、唇形同步、音效与质量审计。

依赖方向单向向下：Agent → `llm_client` / `pipeline.*` / `core.*` / `adapters.*`，模块间不互相循环引用，便于替换实现（如多种 audio sync manager）。
