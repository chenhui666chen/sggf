本模块以 Python 包形式组织，按职责拆分为三个子包与一组扁平的共享工具文件：
- dreamweaver_agent_pkg：封装 DreamWeaver 视频生成管线（i2v/t2v 生成、Kling Omni 调用、幻灯片、提示词管理）。
- painter_pkg：封装图像编辑管线（t2i/edit 流水线、关键帧、Midframes、库管理）。
- storyboarder_pkg：封装分镜构建（音频同步、时长计算、实体模型、镜头配置、变体生成、视频分镜）。
- 扁平层提供跨子包复用的基础设施：asset_library（资产索引）、character_manager/voice_consistency_manager（角色与音色一致性，含 simple/performance/high_performance 三种实现）、audio_sync_manager（多种音频同步策略）、llm_client（LLM 客户端）、prompt_fragments（提示词片段）、camera_states/camera_tree（镜头状态与树结构）、vlm_utils/image_edit_utils/sound_effect_manager/lipsync_manager 等。
- 顶层入口 agents/__init__.py 仅做轻量 re-export，使外部通过 `import agents` 即可按需导入各 Agent 模块，形成“子包实现 + 扁平共享 + 顶层统一导出”的分层契约。
