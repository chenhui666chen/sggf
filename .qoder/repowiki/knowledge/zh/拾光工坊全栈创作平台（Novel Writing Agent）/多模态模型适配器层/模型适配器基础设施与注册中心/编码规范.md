- 所有具体适配器继承 BaseAdapter 并实现 _map_task_to_request、_call_api、_parse_response 三个抽象方法，统一通过 generate() 流程编排。
- 适配器类通过 @register_model(model_id) 装饰器声明自身 ModelSpec，由 registry 在首次访问时自动完成注册。
- 错误处理统一走 _map_error_code → ErrorCode 枚举映射，最终封装为 success=False 的 GenerationResult，而非直接抛异常。
- 第三方 API 密钥与基础 URL 集中在 _shared.py 顶部以环境变量读取并带 fallback 默认值，避免散落在各适配器中。
- 需要异步调用的场景通过 _run_async_sync 在独立线程内执行 asyncio.run，保证同步调用点也能安全触发异步逻辑。
- Registry 的所有写操作均通过 self._state_lock (RLock) 保护，读路径先调用 _ensure_builtin_registration 确保内置适配器已加载。
