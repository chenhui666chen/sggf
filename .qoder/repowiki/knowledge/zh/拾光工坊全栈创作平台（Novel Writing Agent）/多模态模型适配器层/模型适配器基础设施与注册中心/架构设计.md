模块由四层构成：
- 抽象层（base.py）：定义 GenerationResult、AdapterConfig 两个核心 dataclass，以及 BaseAdapter、BaseImageAdapter、BaseVideoAdapter 三个 ABC。generate() 是统一入口，内部串联 _pre_process_task → _map_task_to_request → _call_api → _parse_response → _post_process_result，并统一计算 latency/cost/trace；错误通过 _map_error_code 映射到 ErrorCode。
- 共享工具层（_shared.py）：集中存放 DASHSCOPE/VOLCENGINE/VIDU/MUREKA 等第三方 API 的密钥、基础 URL，以及 _poll_*_task 异步任务轮询函数和 _encode_image 图片编码工具，被具体适配器复用。
- 兼容桥接层（adapter_helpers.py）：提供 SimpleGenerationResult、SimpleAdapter、SimpleAdapterFactory 等旧接口包装器，将 legacy 调用转调到 core.unified_media_runtime，同时暴露 generate_image/generate_video/edit_image/chat_messages/synthesize_speech 等便捷函数。
- 注册中心（registry.py）：ModelRegistry 采用线程安全单例（双重检查锁 + RLock），维护 _specs/_adapter_classes/_adapter_instances/_performance_stats/_config_cache；通过 register_model 装饰器自动注册，支持从 config/models.yaml 动态加载，并提供 find_capable_models、get_adapter（含配置指纹缓存）等能力查询与实例获取接口。
依赖方向单向：adapter_helpers → registry → base；_shared 仅被具体适配器使用，不反向依赖上层。
