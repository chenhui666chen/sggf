本模块由五个相互独立的适配/工具文件组成，承担两类职责：
- 兼容桥接层：`legacy_bridge.py` 通过 `ModelAdapterFactory.create` 按优先级依次尝试 legacy runtime wrapper → registry 新适配器 → 旧 `model_adapters` 类，并用 `LegacyAdapterWrapper` / `LegacyGenerationResult` 把新 `BaseAdapter.generate(TaskSpec)` 返回的 `NewGenerationResult` 适配回旧式 `{success, data, error, metadata, cost}` 结构；`legacy_runtime_wrappers.py` 以 `_BaseLegacyRuntimeWrapper` 为基类，针对 wan2.6-t2i、wan2.7-t2v/i2v/r2v、qwen3-vl-plus、qwen-image-edit-*、qwen3-tts、minimax-speech-* 等模型各实现一个 Wrapper，统一通过 `adapter_helpers` 中的 `generate_image/generate_video/chat_messages/analyze_image/analyze_video/synthesize_speech_sync` 等函数调用新系统，并由 `_RUNTIME_WRAPPER_CLASSES` 字典集中注册，`create_runtime_wrapper(name, config)` 负责按 name 查找实例化。
- 独立工具：`content_safety_checker.py` 基于 `SENSITIVE_KEYWORDS` + `REPLACEMENT_SUGGESTIONS` 两级词典对 prompt 做敏感词检测与三级严重度分类，并提供 `auto_fix` / `generate_safe_prompt` 多策略替换；`rate_limiter.py` 用 `deque` + `threading.Lock` 实现进程内单例 `RateLimiter`，支持 per-minute 与 per-day 双窗口限流并通过 `get_rate_limiter(key, ...)` 共享实例；`prompt_optimizer.py` 定义 `PromptRule` 数据类与 `VIDEO_PROMPT_RULES` / `IMAGE_PROMPT_RULES` / `KLING_VIDEO_RULES` 规则集，`PromptOptimizer.optimize` 按 model_id 与 modality 选择规则并执行 remove/replace/prefix/suffix 变换，模块级 `_optimizer` 作为单例暴露。
依赖方向单向向下：bridge → wrappers → adapter_helpers → registry/base；工具模块之间无互相引用。
