- 每个 legacy runtime wrapper 都继承 `_BaseLegacyRuntimeWrapper`，声明 `TARGET_MODEL_ID` 常量并在 `generate(**kwargs)` 中委托给 `adapters.adapter_helpers` 对应函数，最后统一用 `_legacy_simple_result` 或手动构造 `LegacyCompatResult` 返回。
- 需要对外暴露的可复用对象（`RateLimiter`、`PromptOptimizer`）均采用模块级单例模式，通过 `_xxx: Optional[T] = None` 全局变量配合工厂函数（`get_rate_limiter` / `get_prompt_optimizer`）懒初始化。
- 配置类使用 `@dataclass(frozen=True)` 或 `@dataclass` 定义（如 `RateLimitConfig`、`ContentSafetyIssue`、`PromptRule`），并通过可选字段 + 默认值表达可选参数。
- 动态注册采用模块级字典集中管理：`_RUNTIME_WRAPPER_CLASSES` 映射 name→wrapper class，`ModelAdapterFactory._adapters` 映射 name→adapter class，新增类型只需在字典中添加条目。
- 对外部可能缺失的模块（如 `adapters.model_adapters`）采用 `try/except ImportError` 包裹的延迟导入，确保 bridge 在受限环境中仍可被 import。
