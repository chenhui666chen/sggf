本模块包含两套并行的适配器体系：
- 旧版适配器（model_adapters.py）：以 `BaseModelAdapter` 抽象基类为核心，通过 `RUNTIME_WRAPPER_NAME` + `_delegate_runtime` 动态委托给 `adapters.legacy_runtime_wrappers.create_runtime_wrapper` 实现，封装了 HTTP 重试、指数退避、DashScope 安全策略自动降级、TTS 音色 ID 归一化等通用逻辑；具体子类如 `Wan26T2IAdapter`、`Qwen3VLPlusAdapter`、`Qwen3TTSAdapter`、`MiniMaxSpeech*` 等仅负责参数映射。
- 新版适配器（qwen_multimodal_adapter.py、wan26_video_adapter.py、wanx_adapter.py）：继承 `BaseAdapter` / `BaseImageAdapter` / `BaseVideoAdapter`，通过 `@register_model` 装饰器注册到统一 registry，每个适配器必须实现 `get_model_spec()`、`_map_task_to_request()`、`_call_api()`、`_parse_response()` 四个方法，并使用 `AdapterConfig` 从环境变量（如 `WAN_T2V_API_KEY`、`DASHSCOPE_BASE_URL`）构建配置。
- `new_models_adapters.py` 作为向后兼容的 re-export hub，将 `adapters.dashscope`、`adapters.volcengine`、`adapters.vidu_platform`、`adapters.mureka` 子包全部 `from ... import *` 暴露，供上层按旧路径导入。
- 依赖方向：适配器 → `adapters.base`（抽象基类）、`adapters.registry`（注册表）、`schemas.model_spec` / `schemas.task_spec`（规格定义），不反向依赖上层业务。
