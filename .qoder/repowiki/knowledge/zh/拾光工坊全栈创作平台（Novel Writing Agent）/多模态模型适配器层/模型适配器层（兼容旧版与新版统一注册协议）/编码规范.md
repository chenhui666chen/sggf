- 每个适配器类通过 `@register_model("<model_id>")` 装饰器声明模型标识，并在 `get_model_spec()` 中返回完整的 `ModelSpec`（含 modality、capabilities、constraints、rate_limit 等元数据）。
- 配置统一通过 `_build_*_config(prefix, default_model_name)` 辅助函数从环境变量构建 `AdapterConfig`，优先取 `{PREFIX}_API_KEY`/`BASE_URL`/`MODEL_NAME`，再回退到 `DASHSCOPE_*` 全局变量。
- 本地文件路径在请求前统一通过 `_encode_local_or_remote_*` 工具函数转换为 `data:<mime>;base64,<encoded>` 或透传 http(s) URL，OSS 资源通过 `X-DashScope-OssResourceResolve: enable` 头开启服务端解析。
- HTTP 请求统一使用 `requests.Session` 复用连接，并在 `_call_api` 中实现 429 的 Retry-After 等待与指数退避重试，错误信息通过 `_extract_error_message` 提取 code/message/request_id 拼接成可读字符串。
- 响应解析统一返回 `GenerationResult(success=..., task_id=..., model_id=..., outputs=..., metadata=..., raw_response=...)`，失败时设置 `error` 和 `error_code` 字段。
- 旧版适配器通过 `RUNTIME_WRAPPER_NAME` 类属性 + `_delegate_runtime(method_name, **kwargs)` 动态委派到 legacy runtime wrapper，子类仅做参数映射，不直接写 HTTP 代码。
