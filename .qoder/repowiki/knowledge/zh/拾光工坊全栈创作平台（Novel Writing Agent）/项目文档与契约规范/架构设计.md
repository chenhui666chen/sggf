该模块为纯文档仓库，按主题划分目录：`contracts/` 存放前后端共享的 JSON Schema 契约及其派生产物说明（如 `USER_ASSET_LOCAL_STORAGE_METADATA_CONTRACT.md` 通过 `scripts/generate_user_asset_local_storage_contract.py` 生成 TS/Python 绑定并由 CI 校验）；其余 `.md` 文件按业务域组织，包括 Audiobook 任务队列与可观测性计划、模型接入参考（覆盖文本 LLM、媒体智能调度链、历史兼容层）、本地优先资产架构、PostgreSQL 部署、角色识别使用指南、TTS 提示词优化等。文档之间通过交叉引用保持关联，例如契约文档引用前端/后端具体实现路径，模型接入参考列出各适配器文件与配置 YAML 的位置，形成“文档 → 代码路径”的双向导航结构。
