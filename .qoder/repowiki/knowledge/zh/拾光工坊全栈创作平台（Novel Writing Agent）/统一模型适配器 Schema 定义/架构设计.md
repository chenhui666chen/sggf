模块以 Python dataclass + Enum 为核心，通过 `__init__.py` 统一暴露所有公共类型，形成三层结构：
- 基础层 `common.py`：定义跨领域枚举（Modality、ModelStatus、SupportLevel、Priority、ErrorCode、ContentType）及通用工具函数（ratio/dimensions 转换），被其他文件复用。
- 任务层 `task_spec.py`：定义无 provider 绑定的统一任务语义对象 TaskSpec，以及 ReferenceSpec、AudioSpec、PriorityProfile 和构建器 TaskSpecBuilder。
- 模型规格层 `model_spec.py`：定义 ModelSpec 及其子结构（ConstraintSpec、QualityMetrics、CostProfile、RateLimitConfig、ParameterSpec、CapabilityFeature、BestPractice、FallbackStrategy），提供 `can_handle`、`estimate_cost`、`estimate_latency` 等决策方法。
- LLM 扩展层 `unified_model_spec.py`：在 ModelSpec 基础上扩展 UnifiedModelSpec、LLMCapability、LLMConstraints、APIConfig、RoutingConfig、PerformanceProfile、LLMTaskSpec、LLMResult，支持多模型类型（LLM/IMAGE/VIDEO/AUDIO/EMBEDDING/TTS）的统一调度。
- JSON Schema 层：`frame_spec.json`、`review_issue.json`、`story_request.json`、`storyboard_item.json` 使用 draft-07 规范描述结构化输入，其中 storyboard_item 引用 frame_spec。
依赖方向单向：unified_model_spec → common；model_spec → common；task_spec → common；JSON Schema 独立存在。
