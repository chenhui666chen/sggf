- 每个脚本均为独立可执行 CLI，使用 `#!/usr/bin/env python3` 开头并通过 `argparse` 或 `sys.argv` 解析参数，最后以 `raise SystemExit(main())` 返回状态码。
- 脚本通过 `PROJECT_ROOT = Path(__file__).resolve().parents[1]` 定位仓库根目录，并 `sys.path.insert(0, str(PROJECT_ROOT))` 后再导入项目核心包。
- 对外暴露的公共接口集中在 `protocols.py`，由 `__init__.py` 统一 re-export，其他脚本通过 `from scripts import ...` 或直接 import `scripts.protocols` 使用。
- 日志统一使用 `logging.getLogger(__name__)` 并以 INFO/ERROR/WARNING 分级输出，错误路径通过 `except Exception as e` 捕获并打印 traceback。
- 结果对象采用 `dataclass` 封装（如 `IntegrationCheckResult`），提供 `is_passed`、`status_label`、`to_dict()` 等属性与方法，便于统一格式化输出。
