测试文件按被测模块组织，每个 `test_*.py` 对应一个或一组相关功能：
- `adapters/` 相关测试集中在 `test_adapter_helpers_*`、`test_model_adapters_*`、`test_wan*`、`test_doubao_*`、`test_wanx_*` 等文件中，通过 monkeypatch 替换 `_get_media_runtime`、`registry.get_adapter` 等依赖。
- `core/model_catalog_runtime.py` 由 `test_model_catalog_runtime.py` 通过临时 JSON 快照文件和 `MODEL_CATALOG_RUNTIME_SNAPSHOT_PATH` 环境变量驱动。
- `agents/asset_library` 的模型解析逻辑由 `test_asset_library_runtime_model_selection.py` 验证，使用 monkeypatch 注入 `get_model_info`。
- 复杂集成测试如 `test_workflow_story_expansion.py` 在文件顶部动态将 `PROJECT_ROOT` 和 `backend` 加入 `sys.path`，并自建 `_FakeDBSession`、`_FakeQuery` 等 mock 类模拟 SQLAlchemy 查询接口。
- 异步与并发隔离测试（如 `test_llm_adapter_loop_isolation.py`）通过 `@pytest.mark.asyncio` 标记并使用 `unittest.mock.patch.dict` 替换 `openai`、`httpx` 模块。
- 所有测试均使用 `from __future__ import annotations` 启用 PEP 563 延迟求值，避免导入循环。
