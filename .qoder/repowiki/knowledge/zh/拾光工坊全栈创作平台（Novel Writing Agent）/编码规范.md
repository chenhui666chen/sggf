- 所有模型适配器的能力描述与输入输出契约集中定义在 schemas_common 的 JSON Schema 中，由 core_engine 的 ModelRegistry 统一注册与发现
- Celery Worker 按业务域划分队列（audiobook、dreamweaver），任务通过 Redis Broker 分发并由对应队列的消费者处理
- 配置项统一通过环境变量注入，禁止硬编码敏感信息，docker-compose.yml 中的默认凭证仅用于开发环境
- 前后端数据契约通过 Python 脚本生成 TypeScript 类型文件，由 tests_root 中的契约测试保证两端一致性
- 部署脚本采用分层 include/exclude 规则（backend/frontend/agents/adapters/pipeline/shared/config），避免将 venv、node_modules、__pycache__ 等无关文件上传
