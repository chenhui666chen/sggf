## 简介
本文件面向“梦境编织者”视频生成任务，系统性梳理文本转视频（T2V）与图像转视频（I2V）的实现机制。内容覆盖：
- 任务调度策略、GPU资源管理与批量处理能力
- 视频质量控制、帧率调整与分辨率转换流程
- 任务状态跟踪、进度反馈与中断恢复
- 监控API、性能分析与故障诊断方法
- 多模型支持、负载均衡与容错设计

## 项目结构
围绕视频生成的代码主要分布在以下层次：
- Agent层：负责编排T2V/I2V生成流程、提示词构建、分镜与幻灯片合成等
- Adapter层：对接多家视频生成厂商（如DashScope、Vidu、Volcengine等），屏蔽差异
- Backend服务：提供Celery异步任务、批处理、数据库持久化、监控与调度API
- Pipeline：统一媒体处理（FFmpeg）、预设参数、状态机驱动

## 架构总览
整体采用“Agent编排 + 多Adapter适配 + Celery异步任务 + FFmpeg后处理”的分层架构。请求进入后端API后，由调度模块选择合适模型与策略，将任务入队；Worker消费任务，调用对应Adapter生成视频；完成后经FFmpeg进行统一质量与规格处理，最终落库并推送进度。

```mermaid

participant Agent as "Dreamweaver Agent"
participant Adapter as "视频Adapter"
participant Media as "FFmpeg管线"
participant DB as "数据库"
Client->>API : 提交T2V/I2V任务
API->>Scheduler : 解析参数/选择模型
Scheduler-->>API : 返回任务ID
API->>Queue : 入队(含批次/优先级)
Queue-->>Worker : 拉取任务
Worker->>Agent : 执行生成流程
Agent->>Adapter : 调用具体厂商接口
Adapter-->>Agent : 返回视频URL/二进制
Agent->>Media : 转码/帧率/分辨率/质量处理
Media-->>Agent : 标准化产物
Agent->>DB : 更新任务状态/元数据
Agent-->>Client : SSE/WebSocket进度事件
Client->>API : 查询任务状态/下载结果
```

### T2V/I2V生成器（Agent）
- 职责：组装提示词、参数校验、调用Adapter、聚合结果、触发后处理
- 关键能力：
  - 提示词模板与上下文注入（场景/角色/风格）
  - 参数规范化（时长、分辨率、帧率、质量档位）
  - 错误分类与重试策略（网络/配额/超时）
  - 中间产物缓存与断点续跑

```mermaid
flowchart TD
Start(["开始"]) --> Parse["解析输入<br/>文本/图像/参数"]
Parse --> Validate{"参数合法?"}
Validate --> |否| Err["返回错误"]
Validate --> |是| BuildPrompt["构建提示词与上下文"]
BuildPrompt --> SelectModel["选择模型/策略"]
SelectModel --> CallAdapter["调用Adapter(T2V/I2V)"]
CallAdapter --> ResultOK{"生成成功?"}
ResultOK --> |否| Retry["重试/降级/熔断"]
Retry --> CallAdapter
ResultOK --> |是| PostProc["FFmpeg后处理<br/>分辨率/帧率/质量"]
PostProc --> Persist["持久化结果/状态"]
Persist --> Notify["推送进度/完成事件"]
Notify --> End(["结束"])
```

- 背压与限流：上游限流保护下游，防止雪崩

## 故障诊断指南
- 常见问题：
  - 适配器超时/配额不足：检查限流配置与重试策略
  - FFmpeg失败：核对输入格式、预设参数与编码选项
  - 任务堆积：观察队列深度与Worker数量，扩容或降载
  - 结果不一致：检查随机种子、提示词版本与参数漂移
- 诊断步骤：
  - 查看任务事件日志与状态机流转
  - 抓取Adapter请求/响应报文与耗时
  - 检查FFmpeg输出与质量检测结果
  - 关联监控指标（延迟、错误率、GPU占用）
