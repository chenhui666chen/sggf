## 简介
本文件面向“实验任务处理系统”，聚焦提示词进化、内容变体生成与A/B测试三大能力。文档从系统设计、数据流、调度优化、资源隔离、结果缓存、监控界面、数据分析与报告生成、沙箱环境与安全权限等方面，提供循序渐进的说明，帮助读者快速理解并高效使用该系统。

## 项目结构
实验相关代码主要分布在后端服务的以下模块：
- API层：暴露实验创建、执行、查询与统计接口
- 服务层：实现提示词进化、样本管理、冠军晋升、策略守卫、评审服务等核心逻辑
- 模型层：定义实验、版本、指标等持久化实体
- 任务层：异步执行实验任务，解耦耗时操作
- 配置与安全：集中管理环境变量、权限控制与访问校验
- 缓存与批处理：提升吞吐与稳定性
- 内容变体与A/B测试：变体生成、执行、指标聚合与分析
- 沙箱与报告：安全隔离执行与结果报告输出

## 核心组件
- 提示词进化调度器：负责实验生命周期编排、迭代计划、并发控制与重试
- 样本管理器：负责采样策略、样本池维护、质量评估与多样性控制
- 冠军晋升服务：基于指标阈值与统计显著性进行版本晋升与回滚
- 策略守卫：对进化策略进行约束与审计，防止越权或异常策略生效
- 评审服务：集成多源评审（LLM/规则/人工），统一评分与反馈闭环
- 内容变体生成器：按模板、参数与上下文生成多样化内容变体
- A/B测试运行器：流量分配、分组、执行与结果收集
- 指标聚合器：汇总业务与系统指标，支持多维度统计
- 数据收集器：埋点采集、清洗与入库
- 分析引擎：统计检验、显著性分析与洞察生成
- 沙箱执行器：隔离执行用户脚本/策略，限制资源与权限
- 报告生成器：导出可视化报告与对比分析
- 版本管理器：实验版本、分支与发布管理
- 缓存系统：热点数据与中间结果缓存
- 批处理器：批量任务拆分、去重与失败重试
- 配置与安全：环境变量加载、鉴权与授权

## 架构总览
系统采用分层架构与事件驱动的任务编排，API层接收请求后交由服务层处理，关键耗时操作通过任务队列异步执行，结果经缓存与批处理优化后返回。

```mermaid

participant API as "实验API"
participant Scheduler as "进化调度器"
participant SampleMgr as "样本管理器"
participant Runner as "A/B运行器"
participant Metrics as "指标聚合器"
participant Cache as "缓存系统"
participant DB as "数据库"
Client->>API : "创建实验/启动A-B测试"
API->>Scheduler : "编排实验流程"
Scheduler->>SampleMgr : "生成/选择样本"
SampleMgr-->>Scheduler : "样本集"
Scheduler->>Runner : "分发变体执行"
Runner->>Metrics : "上报指标"
Runner->>Cache : "写入中间结果"
Runner->>DB : "持久化实验记录"
Metrics-->>API : "聚合结果"
API-->>Client : "返回状态/结果"
```

- 职责：实验生命周期管理、迭代计划、并发控制、重试与补偿
- 关键点：
  - 支持按项目/主题维度组织实验
  - 可配置迭代轮次、样本规模与评审阈值
  - 与样本管理器协作，确保样本质量与多样性
  - 与冠军晋升服务联动，自动升级最优策略

```mermaid
flowchart TD
Start(["开始"]) --> Init["初始化实验上下文"]
Init --> Plan["制定迭代计划"]
Plan --> SampleGen["调用样本管理器生成样本"]
SampleGen --> Review["触发评审服务评分"]
Review --> ScoreCheck{"分数达标?"}
ScoreCheck -- "否" --> Retry["重试/调整策略"]
Retry --> SampleGen
ScoreCheck -- "是" --> Promote["提交冠军晋升"]
Promote --> End(["结束"])
```
