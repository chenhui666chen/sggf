## 简介
本文件为“梦境编织者”资产库管理的功能文档，面向角色、场景、道具等资产的分类、卡片网格展示与详情查看；涵盖提供者参考对话框、资产再生成对话框、批量操作、搜索过滤与标签管理、元数据编辑；说明预览与缩略图生成、格式支持；并覆盖导入导出、版本控制与协作共享；最后给出健康检查、损坏修复与数据备份机制。

## 项目结构
资产库相关能力由后端 API、领域模型、服务层与管线工具共同实现：
- 领域模型与数据库迁移：用户资产记录、评分、语音参考资产等
- API 路由：用户资产接口、资产工作室接口
- 服务层：模型目录同步与投影、任务编排
- 管线工具：媒体预设、角色再生成脚本
- 前端：页面、组件、Hook、类型与服务调用（位于 frontend/src）
- 契约文档：本地存储元数据与来源载荷形状

## 架构总览
资产库采用前后端分离架构，前端通过 API 服务层与后端交互；后端以 FastAPI 暴露 RESTful 接口，结合数据库持久化与对象存储（本地/云盘）管理媒体文件。关键流程包括：
- 资产列表与详情：分页查询、过滤、排序、详情加载
- 元数据编辑：更新资产属性与标签
- 预览与缩略图：异步生成与缓存
- 再生成：提交任务、进度回调、版本归档
- 导入导出：清单解析、批量写入/读取、并发处理

```mermaid
sequenceDiagram
participant U as "用户"
participant FE as "前端"
participant API as "后端API(user_assets)"
participant DB as "数据库"
participant FS as "文件存储"
participant Q as "任务队列"
U->>FE : 打开资产库
FE->>API : GET /api/v1/assets?page=...&filter=...
API->>DB : 查询资产列表(分页/过滤)
DB-->>API : 返回资产摘要
API-->>FE : 返回列表数据
FE->>API : GET /api/v1/assets/{id}
API->>DB : 查询详情与版本历史
API->>FS : 获取缩略图/媒体URL
FS-->>API : 返回URL
API-->>FE : 返回详情
U->>FE : 点击“再生成”
FE->>API : POST /api/v1/assets/{id}/regenerate
API->>Q : 入队再生成任务
Q-->>FE : SSE/WS 推送进度
Q-->>API : 完成回调，创建新版本
API-->>FE : 返回新版本信息
```
