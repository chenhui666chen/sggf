## 核心组件
- UserAssetCard：单条资产卡片的UI与交互实现，负责渲染缩略图、元数据、操作按钮，处理点击预览、右键菜单、拖拽排序、批量选择等。
- useUserAssets：卡片所在页面的数据与状态Hook，封装列表加载、分页、筛选、排序、批量操作、本地缓存与乐观更新。
- userAssetsService：HTTP请求封装，统一调用后端用户资产API，处理错误、重试、超时与取消。
- 类型定义：userAssetTypes.ts 定义资产实体、查询参数、响应结构，保证前后端契约一致。
- 后端API：user_assets.py 暴露CRUD接口；user_asset.py 定义Pydantic Schema；user_asset_record.py 定义数据库模型。

## 架构总览
前端通过页面容器聚合卡片列表，卡片组件通过Hook与服务层发起请求，后端以REST API提供服务，Schema与Model确保数据结构一致性。

```mermaid
sequenceDiagram

participant Card as "UserAssetCard"
participant Hook as "useUserAssets"
participant Service as "userAssetsService"
participant API as "后端 user_assets.py"
participant Schema as "user_asset.py"
participant Model as "user_asset_record.py"
UI->>Card : 渲染卡片
Card->>Hook : 订阅列表/选中/操作回调
Hook->>Service : 获取资产列表(分页/筛选)
Service->>API : GET /api/v1/user-assets
API->>Schema : 校验请求/响应
Schema->>Model : 映射到数据库模型
Model-->>Schema : 返回记录
Schema-->>API : 序列化响应
API-->>Service : JSON数据
Service-->>Hook : 解析并缓存
Hook-->>Card : 更新状态与UI
```

## 故障排查指南
- 常见问题
  - 缩略图无法加载：检查URL有效性、跨域、CDN状态
  - 拖拽排序失败：确认后端接口权限与数据一致性
  - 批量操作无响应：检查网络超时与重试策略
- 调试技巧
  - 启用网络面板日志，观察请求/响应
  - 使用浏览器控制台打印状态变化
  - 后端日志定位错误堆栈
- 恢复策略
  - 自动重试与指数退避
  - 离线模式与队列重试
