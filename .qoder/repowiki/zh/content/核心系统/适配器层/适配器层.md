## 简介
本技术文档围绕“适配器层”展开，系统性阐述适配器模式在本项目中的设计理念与实现方式。内容涵盖：
- 基础接口定义、抽象类设计与具体适配器实现
- 适配器注册机制（动态加载、依赖注入、服务发现）
- 多类型适配器实现（LLM、图像生成、视频处理、音频处理）
- 错误处理、重试机制与降级策略
- 自定义适配器开发指南（模板与测试方法）
- 配置管理与环境变量处理

目标是帮助开发者快速理解并扩展适配器体系，确保系统对多厂商、多模态能力的统一接入与稳定运行。

## 项目结构
适配器层位于 adapters 目录，采用“按能力域+按厂商”的二维组织方式：
- 公共基类与工具：base.py、_shared.py、adapter_helpers.py、registry.py
- 模型适配桥接：model_adapters.py、new_models_adapters.py
- 多模态与专用适配器：qwen_multimodal_adapter.py、wan26_video_adapter.py、wanx_adapter.py
- 厂商实现：dashscope、volcengine、mimo、mock 等子包
- 脚本与验证：scripts/verify_all_adapters.py

## 核心组件
- 基础接口与抽象类
  - 定义统一的输入输出契约、能力标签、参数校验与结果归一化
  - 提供通用生命周期钩子（初始化、预热、关闭）、上下文传递与日志埋点
- 注册中心
  - 支持按能力维度（文本、图像、视频、音频）与厂商维度的命名空间注册
  - 提供动态发现、按需加载、版本选择与优先级排序
- 共享工具与辅助函数
  - 参数标准化、幂等键生成、速率限制、缓存键构造、错误码映射
- 模型适配桥接
  - 将上层模型解析与路由逻辑与具体厂商实现解耦
  - 兼容新旧两套模型描述规范，提供自动转换与回退路径

## 架构总览
适配器层通过“统一接口 + 注册中心 + 运行时调度”的架构，屏蔽底层差异，向上提供一致的能力访问方式。

```mermaid
classDiagram
class BaseAdapter {
+initialize(config)
+validate_params(params)
+execute(request) Response
+health_check() bool
+close() void
}
class Registry {
+register(capability, name, adapter_class)
+resolve(capability, name) Adapter
+list_available() list
+get_priority(name) int
}
class ModelResolver {
+resolve_model(spec) Adapter
+fallback_chain(spec) list
}
class UnifiedRegistry {
+discover() map
+load_if_missing(name) Adapter
+inject_dependencies(adapter) void
}
class FallbackManager {
+try_next(fallbacks) Result
+on_failure(error) void
}
BaseAdapter <|-- LLMAdapter
BaseAdapter <|-- ImageAdapter
BaseAdapter <|-- VideoAdapter
BaseAdapter <|-- AudioAdapter
Registry --> BaseAdapter : "管理实例"
ModelResolver --> Registry : "查询能力"
UnifiedRegistry --> Registry : "增强发现与注入"
FallbackManager --> ModelResolver : "降级策略"
```

## 详细组件分析

### 基础接口与抽象类设计
- 目标：为所有适配器提供一致的契约，包括参数校验、执行入口、健康检查与资源释放
- 关键职责：
  - 参数规范化与校验（必填字段、类型约束、范围限制）
  - 执行流程封装（请求构建、调用、响应解析、错误映射）
  - 可观测性（指标上报、链路追踪、结构化日志）
  - 生命周期管理（初始化、预热、关闭）


### 适配器注册机制（动态加载、依赖注入、服务发现）
- 注册中心职责：
  - 维护能力到实现的映射表，支持按名称与优先级检索
  - 提供插件式动态加载，避免启动时全量导入
  - 支持依赖注入（如 HTTP 客户端、密钥管理器、限流器）
- 服务发现：
  - 基于配置文件或环境变量扫描可用适配器
  - 结合模型目录与能力标签进行匹配
- 统一注册增强：
  - 在 core/unified_registry.py 中集成发现、懒加载与依赖注入

```mermaid
sequenceDiagram
participant App as "应用启动"
participant Reg as "注册中心"
participant UR as "统一注册(发现)"
participant Mod as "模型解析"
participant FB as "降级管理器"
App->>UR : discover()
UR-->>App : 可用适配器清单
App->>Reg : register(capability, name, class)
App->>Mod : resolve_model(spec)
Mod->>Reg : resolve(capability, name)
Reg-->>Mod : 返回适配器实例
Mod->>FB : 若失败则尝试降级链
FB-->>Mod : 下一个候选
Mod-->>App : 最终适配器
```
